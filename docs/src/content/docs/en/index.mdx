AsterACME is an embeddable Rust ACME client and CLI that manages ACME accounts, certificate issuance, renewal, deployment, and revocation. It is built around **recoverability**: every request is persisted as intent before it is sent, interruptions continue from saved checkpoints, and operations with uncertain outcomes are never replayed automatically.

At a glance:

- Named CA accounts: registration, recovery, contacts, key rotation, deactivation
- Single-domain, multi-SAN, and wildcard certificates; account and certificate keys chosen independently
- Seven validation implementations covering DNS-01, DNS-PERSIST-01 (draft), HTTP-01, and TLS-ALPN-01
- Saved issuance recovery, ARI (RFC 9773) refresh, single and batch renewal, unattended maintenance
- Multiple deployment targets per certificate with automatic publication after renewal and bounded reload
- Interactive, JSON, and offline inspection output modes
