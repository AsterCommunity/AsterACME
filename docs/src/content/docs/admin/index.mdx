## 运维原则

**数据目录私有**:私钥、账户资料和 provider 凭据都在 data-dir 下。让服务用户独占读写;Unix 下 CLI 会把密钥文件设为 `0600`,但目录本身的访问控制由操作者负责。

**凭据最小授权**:DNS provider token 只授予目标 zone 的 Zone Read + DNS Edit;`--allow-zone` 是附加限制,不能替代凭据本身的最小化。

**审查 reload 命令**:reload 不经 shell 按固定 argv 执行,但命令仍以运行者权限启动进程。配置前确认命令内容;输出会原样展示,不自动脱敏。

**先 staging 后生产**:接入新的 DNS provider executable 或新验证链路时,先用 Let's Encrypt staging(`--ca-directory`)和受控 zone 走通完整签发、恢复与清理,再切生产 CA。
