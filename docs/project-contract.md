# 项目契约

本文保存AsterACME长期产品和可靠性边界。架构归属见[架构概览](architecture.md)，命令细节见[CLI契约](cli-contract.md)，模块细节见[任务路由](task-routing.md)。当前用户要求决定本次范围，代码和测试决定当前实现事实，RFC决定协议要求。

## 产品与协议

- 提供可嵌入Rust库及CLI；纯core无网络/文件/runtime依赖，protocol拥有具名wire结构，领域服务拥有协议推进。
- 端点来自directory、Location或资源字段，不拼惯例URL；保留CA提供的合法精确字符串用于签名，不通过规范化悄悄改写。
- Provider只内置公开生产入口letsencrypt/zerossl/google。默认生产Let's Encrypt；测试端点仅显式指定，不按构建模式切换。
- 未知wire扩展无损保存，不执行未知验证方法。Problem类型注释对应RFC/IANA来源；类型支持不代表新协议流程已经实现。
- 所有账户/证书算法使用共享KeyAlgorithm；账户签名算法与证书密钥算法独立，默认P-256，恢复必须与实际材料及保存类型一致。

## 身份、状态与副作用

- 账户身份是密钥及稳定账户ID/kid，联系人不是登录身份。本地请求意图和最后CA观察分开，离线状态不能冒充远端当前有效。
- 注册/ack/finalize/换钥/吊销先保存意图再发请求；网络超时、取消或响应丢失不授权重放。只有明确拒绝或协议明确允许的badNonce路径解除/重签。
- newOrder丢失Location不自动再下单；完整创建错误证据与CA Order状态分开。终态授权/挑战保留problem并拒绝恢复。
- 换钥保留双钥及日志；明确未发送与结果未知分开。Confirmed只补本地提交，Pending仅用保存新钥对账。确认过的身份/事务快照在重新持锁后复核。
- 证书托管名称与每次操作ID独立。每个世代固定key/CSR；恢复不得生成替代材料，过时世代不得覆盖后续选中的in_use。
- 新证书产物校验并保存后才提升选择；实际持久化catalog决定恢复。Unix in_use使用相对链接，Windows使用可恢复完整副本，两次rename不是原子交换。
- 租约按账户→证书；部署配置锁先于证书锁。后台阻塞写任务持有显式租约/IO许可到结束，取消等待不得提前放锁。
- 查询是快照。CLI提交类型化筛选条件，storage裁剪读取并筛选；执行资格必须在写事务内重新验证。
- 当前尚未正式发布，内部API/schema变更同步全部调用方，不增加旧路径薄转发、旧格式兼容或自动迁移；不得擅自删除用户旧数据。

## 配置、文件和安全

- 统一 `--data-dir`；配置固定为根config.toml，无独立--config或配置内data_dir。根version=1，config.toml使用toml_edit定点修改保留用户注释，未知版本/损坏拒绝自动重置。
- accounts/<name>保存account.toml与account-key.pk8；certs/<name>保存cert.toml和各操作世代。锁集中在根.locks，锁载体存在不代表持锁，不通过删除锁文件释放锁。
- 只有注册可创建账户身份；普通查看/恢复缺密钥时失败关闭。未知用户文件不参与托管删除，不递归清理未证明归属的内容。
- Unix内部密钥/元数据使用私有权限；Windows继承权限并校验reparse/hard-link。Windows替换支持进程重启恢复，不承诺掉电rename目录项持久性。
- 私钥、EAB、provider凭据不进入日志、错误或公开输出。外部reload输出按用户要求展示，不自动脱敏，也不持久化为账户/部署元数据。
- 条款同意绑定实际发现URL，必须明确同意，--yes不代替条款接受。吊销/停用/本地删除语义独立，不因删除本地文件隐式调用CA。

## 验证、续期与部署

- CLI和嵌入者注入ChallengeSolver。ACME拥有方法选择、材料推导、通知与轮询；solver拥有发布、ready、restore、shutdown和终态清理的实际副作用。
- CAA/TXT/HTTP预检由库的可选feature显式提供，返回结构化观察；库默认关闭、CLI默认启用，IssueService不隐式运行预检。本地预检有界且建议性；不能绕过CA验证。取消/超时保留不确定材料；webroot只清理拥有且未修改的文件，实际移走对象再核验身份。
- 临时HTTP/TLS服务共享有界监听生命周期，不自动提权、停其他服务或修改用户网络环境。每个返回路径关闭，取消后不得遗留任务或终端raw mode。
- 续期只调度in_use，沿用保存定义。ARI在窗口内随机选时且相同窗口不重抽，失败保留计划；证书过期后不查询ARI。回退依据实际有效期，短于10天用一半，其余2/3，并在有效窗口内随机提前。
- deploy直接发布普通文件并保持目录路径，状态保存在检查点，不以链接存在推断状态。全部选定文件准备/设权/sync后逐文件替换；全部成功后才reload，不承诺整组原子事务、自动回滚或服务健康。
- 容器挂载与reload命令更新服务的语义由用户负责。reload不经shell，执行/输出/重试有界；不确定结果不自动重放，单目标失败不丢其他目标结果或已签发证书。
- 批量执行保留已提交结果；取消不从外层直接丢弃可能已经提交的事务。JSON一次输出完整结果，不混人类日志。

## 展示与文档

- common/output、time、log、table、terminal是统一展示入口。人类时间UTC，机器时间RFC3339；颜色与控制字符转义在共同边界处理。
- 交互只补输入，不创建另一套业务执行路径；JSON/非TTY不提示。每个业务命令最多一个位置参数，deploy show的两个身份是明确例外。
- 根AGENTS只负责入口和硬约束；契约、实现说明、测试证据、未来设计分开。README/CHANGELOG中英文配对，不把历史验收或计划能力写成当前完成。
