# aster_acme_cli_storage

CLI 的账户文件存储适配，实现 `dyn AccountStore` 和 `dyn AccountKeyStore`。`toml_file` 模块另提供有界读取与缺失配置的加锁、原子初始化；配置 schema 和注释模板由 CLI 定义。`aster_acme` 不依赖本 crate；嵌入式 Aster 服务可提供数据库存储和软件/远程签名器。

当前文件实现支持 Unix，其他平台明确返回不支持，不将继承 ACL 冒充私钥权限保护。AsterFs 的文件锁本身支持跨平台；Windows 私有目录 ACL 仍需单独实现和验收。

布局：

```text
<data-dir>/
  config.toml              # 根 version=1 与 [config]，用户设置
  config.toml.lock         # 配置初始化和读改写共用的锁
  accounts/
    personal/
      account.toml         # 根 version=1 与 [account]，程序维护
      account-key.pk8      # P-256 PKCS#8 DER 私钥
      account.lock         # 密钥、账户操作、远端对账全过程共用
    work/
      account.toml
      account-key.pk8
      account.lock
```

每个名称绑定一个 CA directory 和公钥指纹，名称在本地唯一；显式换 CA 或指纹不匹配时拒绝，不隐式生成新身份。无需 CA 摘要层、names.toml、active-account.toml 或 initialized。`account switch` 更新 config.toml 的 default_account。

`toml_file` 统一有界读取、有限等待锁、取消后的 guard 生命周期、原子替换及文件/目录 sync。配置在锁内读取最新文本再用 toml_edit 修改；账户操作的 lease 覆盖远端请求和持久化，不重复获取自己的锁。锁载体释放后保留，其存在不代表持锁。配置 schema 和模板属于 CLI；账户 schema 属于账户适配器。

- 目录 `0700`、文件 `0600`，拒绝不安全目录、符号链接、硬链接或错误属主。
- macOS 并发首次创建 no-follow 锁文件可能返回 ENOENT；通过同一校验目录描述符重试一次，保留链接和权限检查。
- 使用固定 revision 的 AsterFs 非阻塞锁加有限等待；锁 guard 释放后关闭句柄。
- Unix 文件操作复用 Forge `StateDirectory`，以目录描述符执行 no-follow 打开和原子替换，sync 文件及目录。
- 配置上限 64 KiB，首次写入为 `0600`；已有只读公开配置可为 `0644`，拒绝其他用户可写、链接或错误属主文件。读取不会改动已有目录权限；初始化锁等待有上限，取消后工作线程仍持锁完成原子写入。
- 账户元数据使用 TOML，默认选择保存在配置里，私钥继续使用 PKCS#8 DER。尚未正式发布，不读取或迁移旧 JSON 及旧目录布局，不提供兼容入口。旧目录不会自动清理或移动。
- 元数据 schema 版本为 1；未知版本、损坏 TOML、超限文件均报错，不自动重置。
- 私钥按名称保存后才进入账户注册。取消、超时、注册失败不删除私钥；注册意图与成功元数据分别持久化。
- 恢复/查看使用 `create=false`，不生成密钥。已有账户记录但私钥缺失/损坏或指纹不符时拒绝换钥；孤立私钥也拒绝猜测 CA。先持久化账户身份再写私钥，记录本身代替初始化标记，崩溃后失败关闭。
- 元数据上限 256 KiB，私钥上限 64 KiB，锁默认由调用方设置，允许 0–300 秒之间的非零时长。
- 私钥文件依靠 OS 权限保护，当前不提供静态加密。备份时必须把私钥和元数据一起作为敏感数据保护。

```rust,no_run
use std::{sync::Arc, time::Duration};
use aster_acme::account::{AccountStore, AccountKeyStore};
use aster_acme_protocol::url::AcmeUrl;
use aster_acme_cli_storage::CliAccountStore;

# async fn example() -> Result<(), Box<dyn std::error::Error>> {
let files = Arc::new(CliAccountStore::open("./data", "default", Duration::from_secs(5))?);
let keys: Arc<dyn AccountKeyStore> = files.clone();
let records: Arc<dyn AccountStore> = files;
let directory = AcmeUrl::new("https://acme-staging-v02.api.letsencrypt.org/directory")?;
let signer = keys.signer(&directory, "default", false).await?;
# let _ = (records, signer);
# Ok(())
# }
```

覆盖重启复用、CA/名称隔离、锁冲突/超时/释放、文件损坏/超限/未知 schema、权限、链接拒绝及丢钥不替换。依赖仅从根 workspace 继承。MIT OR Apache-2.0.

account.toml 首行为 `# Managed by aster-acme. DO NOT EDIT this file.`，根版本与 `[account]` 之间空行。`contacts` 为本地设置，`server_contacts` 独立记录 CA 可选返回，不把服务端遗漏当作本地输入丢失。

账户元数据保留 last_status 和 deactivation 状态（not_requested/pending/confirmed）。列表复用 accounts 枚举，返回注册阶段、最后 CA 状态和本地可用性，不加载密钥。停用不删除数据；已停用/撤销或 pending 意图不会作为可用账户供 switch 选择。未发布阶段直接更新 schema，无迁移旧账户格式。

`CliAccountStore::remove` 仅移除所选本地名称：共用账户锁，验证只含已知普通私有文件后，原子 rename 到 .<name>.removing，再 unlink 已知文件并 sync 目录。未知文件、符号/硬链接、锁超时和已有未完成清理目录均报错。后台删除任务持有 lease 到完成，取消不会提早解锁。损坏密钥无需解码即可删除。CLI 负责确认及默认配置条件清理，存储层不执行 CA 停用。

时间字段通过 AccountTimes 在 [account] 下保存 registered_at、last_status_at、last_used_at，采用 UTC RFC 3339；未知值省略。文件适配器和枚举只保留服务提供的时间，不在读取/写盘/删除时自行更新；账户服务统一处理时钟与观察事件。
