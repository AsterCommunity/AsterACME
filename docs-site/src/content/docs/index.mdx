AsterACME 是一个可嵌入的 Rust ACME 客户端与 CLI，管理 ACME 账户、证书签发、续期、部署和吊销。它围绕**可恢复性**设计：每次请求先保存意图再发出，中断后从保存的检查点继续，不自动重放结果不确定的操作。

核心能力一览:

- 具名 CA 账户：注册、找回、联系人、换钥、停用
- 单域名、多 SAN 与通配符证书；账户与证书密钥独立选择
- 七种验证实现覆盖 DNS-01、DNS-PERSIST-01（草案）、HTTP-01、TLS-ALPN-01
- 保存申请后恢复、ARI（RFC 9773）刷新、单次与批量续期、无人值守维护
- 每张证书多个部署绑定，续期后自动发布与有界 reload
- 交互、JSON、离线查看三种输出形态
